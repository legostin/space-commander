# Space Commander

Анализатор места на дисках для Windows: быстрое сканирование, карта диска, очистка кешей и задачи по расписанию. Rust + Tauri 2, интерфейс на React.

## Возможности

- **Сканирование.** Обычный режим обходит папки параллельно и не требует прав. Быстрый режим читает таблицу файлов NTFS (`$MFT`) напрямую — секунды на миллионы файлов, нужны права администратора. Результат кешируется: при следующем запуске карта открывается сразу и обновляется в фоне.
- **Карта диска.** Treemap с цветом по типу файла, список рядом, поиск по именам (`Ctrl+K`, понимает `*.iso`), фильтр скрытых и системных объектов, сканирование отдельной папки.
- **Анализ.** Крупнейшие файлы (в том числе давно не менявшиеся), типы файлов, изменения между сканированиями, игры и программы (Steam, Epic, GOG, реестр), дубликаты по содержимому, экспорт в CSV.
- **Очистка.** Системный мусор, кеши браузеров, приложений и инструментов разработки. У каждого правила видны точные пути и уровень риска; запущенные приложения определяются и по умолчанию пропускаются.
- **Расписание.** Задачи выполняет Планировщик Windows — приложению не нужно быть запущенным. Условия: чистить только при нехватке места, предупреждать о росте папок.
- **Права доступа.** Перед каждым запросом UAC показывается, что именно нужно, почему Windows это ограничивает и что будет без прав.

Интерфейс на восьми языках: русский, английский, испанский, немецкий, французский, португальский (Бразилия), китайский упрощённый, японский. Тёмная и светлая темы.

## Разработка

Нужны Rust (stable, MSVC), Node.js 24+ и WebView2 (есть в Windows 11).

```bash
npm install
npm run tauri dev
```

Проверки:

```bash
npx tsc --noEmit
npm run i18n
cd src-tauri && cargo test --lib
```

Сборка установщика (`src-tauri/target/release/bundle/nsis/`):

```bash
npm run tauri build
```

Ядро можно проверить без интерфейса:

```bash
cd src-tauri
cargo run --release --example scan -- walk C:\
cargo run --release --example scan -- junk
cargo run --release --example scan -- apps
```

Режим `mft C` требует терминала, запущенного от администратора.

## Устройство

| Путь | Что там |
|---|---|
| `src-tauri/src/scan_walk.rs` | Параллельный обход папок |
| `src-tauri/src/scan_mft.rs` | Чтение `$MFT` с тома |
| `src-tauri/src/tree.rs` | Дерево в плоской арене и все запросы к нему |
| `src-tauri/src/junk.rs` | Правила очистки и безопасное удаление |
| `src-tauri/src/snapshot.rs` | Снимки размеров папок и их сравнение |
| `src-tauri/src/cache.rs` | Кеш результата сканирования |
| `src-tauri/src/apps.rs` | Установленные игры и программы |
| `src-tauri/src/schedule.rs` | Задачи Планировщика, история, фоновый запуск |
| `src-tauri/src/lib.rs` | Команды Tauri |
| `src/views/` | Экраны интерфейса |
| `src/locales/` | Переводы интерфейса |

Данные приложения лежат в `%APPDATA%\SpaceCommander` (задачи, история, снимки) и `%LOCALAPPDATA%\SpaceCommander` (кеш сканирования).

## Ограничения

- Только Windows. Быстрый режим — только NTFS.
- В обычном режиме жёсткие ссылки считаются по числу имён, поэтому `C:\Windows\WinSxS` выглядит больше, чем занимает.
- Обход папок и чтение `$MFT` считают немного по-разному: сравнивать сканирования лучше в одном режиме.
